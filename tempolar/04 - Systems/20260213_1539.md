# {{ Task Queue Mechanism}} 

## هدف سیستم
وقتی کلاستر به عنوان Broker عمل می‌کند، از مکانیزمی به نام Task Queue استفاده می‌کند:

| بخش سیستم | نقش در مدل Broker |
|---|---|
| Workflow | درخواست را به کلاستر ارسال (Push) می‌کند. |
| Temporal Cluster | درخواست را در Task Queue ذخیره و مدیریت می‌کند. |
| Worker | به صورت مداوم صف را برای کارهای جدید Poll می‌کند. |
| Persistence Store | دیتابیسی که کلاستر برای حفظ وضعیت Broker از آن استفاده می‌کند. |
