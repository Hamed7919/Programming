قانون اصلی Temporal در مورد شناسه‌ها: در هر لحظه، در یک **Namespace**، تنها یک Workflow Execution با یک Workflow ID مشخص می‌تواند در وضعیت "Running" باشد.

- **دامنه محدودیت:** این محدودیت سراسری است. یعنی دو نوع Workflow متفاوت (مثلاً یکی برای وام و یکی برای سفارش) نمی‌توانند از یک ID یکسان در یک Namespace استفاده کنند.
    
- **Namespace چیست؟** یک واحد منطقی برای جداسازی (Isolation) که اجازه می‌دهد تیم‌های مختلف روی یک کلاستر بدون تداخل کار کنند.
