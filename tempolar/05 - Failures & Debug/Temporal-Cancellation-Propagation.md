# چطور وقتی دکمه Cancel را در Web UI می‌زنید، یک درخواست HTTP در اعماق یک Activity قطع می‌شود؟

1. **کلاستر:** سیگنال لغو را به ورکر می‌فرستد.
    
2. **بWorkflow Context:** مقدار `ctx.Done()` در ورک‌فلو بسته می‌شود.
    
3. **بExecuteActivity:** تمپورال متوجه می‌شود ورک‌فلو لغو شده، پس به ورکرِ اکتیویتی پیام می‌دهد.
    
4. **بActivity Context:** تمپورالِ ورکر، `context.Context` واقعیِ اکتیویتی را Cancel می‌کند.
    
5. **بI/O:** کتابخانه `http` یا `sql` که از این context استفاده می‌کنند، عملیات را متوقف کرده و خطا برمی‌گردانند.
