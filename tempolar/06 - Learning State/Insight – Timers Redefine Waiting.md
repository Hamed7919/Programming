# Learning Insight - Waiting Is Durable

درک عمیق:

در Temporal "صبر کردن" دیگر یک عملیات درون process نیست.

بلکه:
یک Event پایدار در سیستم توزیع‌شده است.

این یعنی:
بWaiting تبدیل می‌شود به بخشی از State ماشین Workflow.

و این دقیقاً همان چیزی است که Temporal را از یک Background Job ساده جدا می‌کند.
