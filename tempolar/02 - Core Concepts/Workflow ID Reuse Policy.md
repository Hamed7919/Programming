این سیاست تعیین می‌کند که وقتی یک Workflow تمام شد (Success یا Failure)، آیا می‌توان دوباره از همان ID برای یک اجرای جدید استفاده کرد یا خیر.

| **Policy**                      | **Description**                                                                              |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| **ALLOW_DUPLICATE**             | (پیش‌فرض) اجازه استفاده مجدد در هر شرایطی پس از پایان اجرای قبلی.                            |
| **ALLOW_DUPLICATE_FAILED_ONLY** | فقط در صورتی اجازه استفاده مجدد می‌دهد که اجرای قبلی با شکست مواجه شده باشد.                 |
| **REJECT_DUPLICATE**            | به هیچ وجه اجازه استفاده مجدد نمی‌دهد (ID برای همیشه رزرو می‌ماند تا زمانی که پاک شود).      |
| **TERMINATE_IF_RUNNING**        | اگر اجرایی با این ID در جریان باشد، آن را می‌کشد (Terminate) و اجرای جدید را جایگزین می‌کند. |
