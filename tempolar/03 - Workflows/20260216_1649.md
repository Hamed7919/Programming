# {{Temporal-Activity-Idempotency}} 

## هدف
چون یک اکتیویتی ممکن است به دلیل شکست‌های شبکه یا تایم‌اوت چندین بار توسط ورکر اجرا شود، کد اکتیویتی **باید** هم‌پان (Idempotent) باشد.

- **تعریف:** اجرای چندباره‌ی اکتیویتی باید نتیجه‌ای کاملاً یکسان با یک‌بار اجرای آن داشته باشد.
    
- **مثال:** اگر اکتیویتی وظیفه کسر وجه از حساب را دارد، باید قبل از تراکنش چک کند که آیا این تراکنش قبلاً با موفقیت ثبت شده است یا خیر (مثلاً با استفاده از یک Transaction ID یکتا).
