# {{Hands-On Exercise #3: Farewell Workflow}} 

عالی 👌  
اینجا یک **راهنمای کامل، مرحله‌به‌مرحله و شفاف** از تمرین _Farewell Workflow_ برات جمع‌بندی می‌کنم — طوری که هر وقت خواستی دوباره انجامش بدی، فقط همین پیام رو ببینی کافی باشه.

---

# 🎯 هدف تمرین چه بود؟

در این تمرین یاد گرفتیم:

1. چطور یک **Activity** بسازیم (جایی برای I/O یا call به microservice)
    
2. چطور Activity را در Worker ثبت کنیم
    
3. چطور Workflow را تغییر بدهیم تا Activity را اجرا کند
    
4. چطور نتیجه را در UI ببینیم
    
5. چطور اجرای Workflow را در UI تحلیل کنیم
    

---

# 🧠 معماری نهایی که ساختیم

```
Temporal Server
      ↓
Worker
  ├── Workflow (Orchestration logic)
  └── Activity (I/O logic)
      ↓
Microservice (شبیه‌سازی شده)
```

Workflow تصمیم می‌گیرد  
Activity کار بیرونی را انجام می‌دهد

## ✅ Step 2 — ساخت Activity

📁 `activities/farewell.go`

```go
package activities

import (
	"context"
	"fmt"
)

type FarewellActivity struct{}

func (a *FarewellActivity) SayGoodbye(ctx context.Context, name string) (string, error) {
	result := fmt.Sprintf("Goodbye, %s!", name)
	return result, nil
}
```

🔹 نکته مهم:

- Activity همیشه `context.Context` می‌گیرد
    
- باید `(result, error)` برگرداند
    

---

## ✅ Step 3 — تغییر Workflow

📁 `workflows/greeting.go`

```go
package workflows

import (
	"time"

	"go.temporal.io/sdk/workflow"
)

func GreetingWorkflow(ctx workflow.Context, name string) (string, error) {

	ao := workflow.ActivityOptions{
		StartToCloseTimeout: time.Second * 5,
	}

	ctx = workflow.WithActivityOptions(ctx, ao)

	var result string

	err := workflow.ExecuteActivity(
		ctx,
		"FarewellActivity.SayGoodbye",
		name,
	).Get(ctx, &result)

	if err != nil {
		return "", err
	}

	return result, nil
}
```

🔹 اینجا Workflow:

- Activity را schedule می‌کند
    
- منتظر نتیجه می‌ماند
    
- نتیجه را برمی‌گرداند
    

---

## ✅ Step 4 — ثبت Workflow و Activity در Worker

📁 `worker/main.go`

```go
package main

import (
	"log"

	"go.temporal.io/sdk/client"
	"go.temporal.io/sdk/worker"

	"temporal-hello/workflows"
	"temporal-hello/activities"
)

func main() {

	c, err := client.Dial(client.Options{
		HostPort: "127.0.0.1:7233",
	})
	if err != nil {
		log.Fatalln("connection error:", err)
	}
	defer c.Close()

	w := worker.New(c, "greeting-tasks", worker.Options{})

	w.RegisterWorkflow(workflows.GreetingWorkflow)

	farewellActivity := &activities.FarewellActivity{}
	w.RegisterActivity(farewellActivity)

	err = w.Run(worker.InterruptCh())
	if err != nil {
		log.Fatalln("worker exited:", err)
	}
}
```

🔹 اگر Activity ثبت نشود → Workflow fail می‌شود

# 🧠 دقیقاً چه چیزهایی یاد گرفتیم؟

## 1️⃣ Workflow ≠ Activity

Workflow:

- Orchestration
    
- تصمیم‌گیری
    
- مدیریت state
    

Activity:

- I/O
    
- HTTP
    
- DB
    
- API
    

---

## 2️⃣ Separation of Concerns

Workflow deterministic است  
Activity non-deterministic است

---

## 3️⃣ Durable Execution

اگر Worker crash کند:  
Temporal با Event History همه چیز را replay می‌کند.

---

## 4️⃣ Task Queue Routing

Workflow روی یک Task Queue اجرا می‌شود  
Worker باید روی همان queue گوش بدهد.

---

## 5️⃣ Observability

در UI می‌توان دید:

- Pending Activities
    
- Retry
    
- Timeout
    
- Event History
