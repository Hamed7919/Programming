# {{Git-Force-Push-Workflow}} # هماهنگ‌سازی Remote پس از Local Reset

**بستر:** Git Workflow **وابستگی:** [[Git-Undo-Pull-Local]]

### هدف

بعد از اینکه لوکال را به عقب برگرداندیم، ریموت (GitHub/GitLab) هنوز در حالت "جلوتر" است. برای حذف آن کامیت‌ها از سرور، باید Force Push انجام شود.

### دستورات اجرایی

- **روش امن (توصیه شده):** `git push --force-with-lease origin [branch-name]` _(این دستور اگر کسی دیگر در این فاصله پوش کرده باشد، عملیات را متوقف می‌کند تا کد کسی پاک نشود)._
    
- **روش تهاجمی:** `git push --force`
    

### چک‌لیست قبل از اجرا

۱. آیا پروژه تیمی است؟ (اگر بله، حتماً هماهنگ شود). ۲. آیا روی برنچ درستی هستم؟ `git branch` ۳. آیا لاگ نهایی تایید می‌شود؟ `git log --oneline -n 5`
