# {{Git-Rebase-Workflow}} # جریان کاری Rebase برای جلوگیری از Merge Commits

**دسته:** #Workflow #Git

### چرا Rebase؟

وقتی با خطای `fetch first` مواجه می‌شوید، اگر از `git pull` معمولی استفاده کنید، یک کامیت اضافی به نام "Merge commit" ساخته می‌شود که تاریخچه را شلوغ می‌کند.

### دستور جایگزین (تمیزتر):

`git pull --rebase origin main`

این دستور تغییرات لوکال شما را موقتاً کنار می‌گذارد، تغییرات جدید سرور را می‌گیرد و سپس تغییرات شما را «روی» آن‌ها می‌چسباند. مثل این است که از ابتدا روی آخرین نسخه سرور کار کرده‌اید.
