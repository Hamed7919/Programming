# مفهوم Alias در شل لینوکس

**دسته:** #Linux #CLI #Productivity

### تعریف

`Alias` یک نام مستعار یا میان‌بر برای یک دستور طولانی است. هدف آن افزایش سرعت در ترمینال و کاهش خطاهای تایپی در مسیرهای طولانی است.

### ساختار دستور (Syntax)

`alias [name]='[command]'`

- **نکته مهم:** بین نام، علامت مساوی و شروع دستور نباید هیچ **فاصله‌ای (Space)** باشد.
    
- **مثال:** `alias gm='cd ~/obsidian-Greatmind/obsidian-Greatmind'`
