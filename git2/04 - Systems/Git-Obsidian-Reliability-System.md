#  # سیستم پایداری تعامل گیت و ابسیدین

**نوع:** #System #Workflow **هدف:** جلوگیری از بروز تداخل (Conflict) در مخازن ابسیدین روی ترموکس.

### قوانین طلایی (Golden Rules)

1. **استاندارد نام‌گذاری:** فقط از حروف، اعداد، `-` و `_` استفاده شود. (ممنوعیت مطلق: `? * : < > |`)
    
2. **مدیریت نادیده‌ها:** پوشه `.obsidian` (به‌ویژه فایل‌های `workspace` و `cache`) حتماً در `.gitignore` باشند.
    
3. **محیط امن (Environment):** ترجیحاً پروژه در حافظه داخلی ترموکس (`~`) باشد تا محدودیت‌های Permission اندروید حذف شود.
    
4. **نظم عملیاتی:** - شروع کار: `git pull`
    
    - پایان کار: `git push`
