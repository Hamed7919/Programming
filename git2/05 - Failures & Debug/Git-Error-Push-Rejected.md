# خطای Rejected (Fetch First) در هنگام Push

**وضعیت:** #Debug #Git **پیام خطا:** `! [rejected] main -> main (fetch first)`

### علت (Root Cause)

تاریخچه (History) محلی شما با تاریخچه ریموت متفاوت است. احتمالاً تغییری را مستقیماً در سایت GitHub اعمال کرده‌اید یا از دستگاه دیگری Push انجام شده است. گیت برای جلوگیری از پاک شدن ناخواسته کدهای دیگران، اجازه Push نمی‌دهد.

### راه‌حل استاندارد

باید ابتدا تغییرات را بگیرید (Pull) و بعد دوباره Push کنید: ۱. `git pull origin main` ۲. اگر تداخلی (Conflict) بود، آن را حل کنید. ۳. `git push origin main`

> [!TIP] نکته حرفه‌ای اگر مطمئن هستید که فایل‌های روی گوشی شما نسخه نهایی و درست هستند و می‌خواهید هر چه روی سرور هست پاک شود (با احتیاط): `git push --force`
