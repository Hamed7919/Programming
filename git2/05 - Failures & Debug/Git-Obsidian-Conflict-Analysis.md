# تحلیل تداخل‌های گیت و ابسیدین (کلاف سردرگم)

**وضعیت:** #Debug #Git #Obsidian

**علت بروز خطا:** ناهماهنگی فایل‌سیستم اندروید با متادیتای Obsidian و Git.

### جدول عیب‌یابی (Troubleshooting)

|**مشکل**|**علت اصلی**|**نتیجه در گیت**|
|---|---|---|
|کاراکترهای غیرمجاز|وجود `?` در نام فایل‌ها|خطای Operation not permitted|
|شاخه معلق (Detached HEAD)|قطع عملیات Pull یا سوئیچ اشتباه|عدم امکان ادغام (Merge) تغییرات|
|تداخل تنظیمات|همگام‌سازی `workspace.json`|بروز Conflict مداوم در هر بار باز کردن برنامه|
|اختلاف تاریخچه|تغییرات همزمان در گوشی و ریموت|خطای rejected (non-fast-forward)|

### استراتژی‌های رفع خطا (Fix Strategies)

1. ب**Sanitization:** حذف کاراکترهای خاص از نام فایل‌ها در GitHub.
    
2. ب**Exclusion:** استفاده از `.gitignore` برای فایل‌های کش و ورک‌اسپیس.
    
3. ب**Hard Reset:** استفاده از `git reset --hard origin/main` برای همگام‌سازی اجباری با سرور.
