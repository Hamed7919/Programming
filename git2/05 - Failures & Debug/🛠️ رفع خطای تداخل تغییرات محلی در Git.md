## مشکل
Your local changes to the following files would be overwritten by merge

----

## تحلیل

این خطا زمانی رخ می‌دهد که شما روی یک یا چند فایل تغییراتی ایجاد کرده‌اید (اما هنوز آن‌ها را **Commit** نکرده‌اید) و همزمان در مخزن آنلاین (Remote)، شخص دیگری روی همان فایل‌ها تغییراتی اعمال کرده است. گیت برای جلوگیری از پاک شدن تغییرات شما، اجازه `pull` نمی‌دهد.

----

## راه حل
### 🚀 راهکارهای سریع (Quick Fixes)

#### ۱. روش Stash (امن‌ترین راه - جابجایی موقت)

اگر می‌خواهید تغییرات فعلی را فعلاً کنار بگذارید، آپدیت را بگیرید و بعد دوباره تغییرات را برگردانید:

Bash

```
git stash       # انتقال تغییرات به حافظه موقت
git pull        # دریافت کدهای جدید از سرور
git stash pop   # بازگرداندن تغییرات خودتان روی کدهای جدید
```
#### ۲. روش Commit (رسمی کردن تغییرات)

اگر تغییرات شما کامل است، آن‌ها را ثبت کنید و سپس تلاش کنید:

Bash

```
git add .
git commit -m "Refactor: توضیحات مربوط به بخش برق خودرو"
git pull
```


> [!IMPORTANT] نکته در این حالت اگر روی خطوط یکسانی تغییر ایجاد شده باشد، باید **Conflict** را دستی حل کنید.

### ۳. روش «بی‌خیالِ تغییرات» (Discard Changes)

**چه زمانی؟** وقتی تغییراتی که دادی دیگر برایت مهم نیست و فقط می‌خواهی فایل‌ها دقیقاً شبیه نسخه روی سرور شوند.

**دستورات:** برای فایل‌های خاص:

Bash

```
git checkout -- "Great mind/موتور/برق خودرو/برق خودرو/فن دمنده.md"
git checkout -- "Great mind/موتور/برق خودرو/برق خودرو/فن مکنده.md"
git pull
```


**نکته حرفه‌ای:** اگر تعداد فایل‌ها زیاد است و می‌خواهی «همه» تغییرات محلی را یکجا پاک کنی تا با سرور یکی شوی:

Bash

```
git reset --hard HEAD
git pull
```

> [!CAUTION] هشدار این دستور (Reset Hard) تمام تغییرات ذخیره نشده شما را **بدون بازگشت** پاک می‌کند. فقط زمانی استفاده کنید که مطمئن هستید چیزی را از دست نمی‌دهید.
