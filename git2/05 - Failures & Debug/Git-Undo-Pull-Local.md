#  {{Git-Undo-Pull-Local}}# بازگرداندن وضعیت Local به قبل از Git Pull



### سناریو

زمانی که `git pull` انجام شده اما از تغییرات راضی نیستیم و هنوز Commit جدیدی روی آن نزده‌ایم.

### راهکارهای بازگشت (Reset)

۱. **استفاده از Reflog (دقیق‌ترین روش):** ابتدا تاریخچه جابجایی HEAD را ببینید: `git reflog` سپس به نقطه قبل از Pull (معمولاً `HEAD@{1}`) بازگردید: `git reset --hard HEAD@{1}`

۲. **استفاده از ORIG_HEAD (سریع‌ترین روش):** گیت همیشه قبل از عملیات‌های حساس، موقعیت قبلی را در `ORIG_HEAD` ذخیره می‌کند: `git reset --hard ORIG_HEAD`

### انواع Reset در این حالت

- `--hard`: تمام تغییرات فایل‌ها را حذف کرده و دقیقاً به گذشته برمی‌گردد.
    
- `--soft`: فقط کامیت را برمی‌گرداند اما تغییرات فایل‌ها را به صورت Stage شده نگه می‌دارد.
