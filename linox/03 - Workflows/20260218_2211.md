# {{Manual Booting via GRUB Shell}} 
# مراحل بوت دستی لینوکس از طریق GRUB Shell

وقتی منوی GRUB نمایش داده نمی‌شود یا فایل کانفیگ خراب است، از این دستورات برای بوت استفاده می‌کنیم:

1. **تعیین پارتیشن بوت:**
   `set root=(hdX,gptY)`

2. **معرفی کرنل و پارتیشن Root:**
   `linux /boot/vmlinuz-[VERSION] root=UUID=[YOUR_UUID] ro`
   *(استفاده از UUID امنیت بیشتری نسبت به /dev/sda دارد)*

3. **معرفی initrd هم‌نسخه:**
   `initrd /boot/initrd.img-[VERSION]`

4. **دستور اجرا:**
   `boot`
