# بهترین روش‌های استفاده از Context

برای نوشتن کد حرفه‌ای (Production-ready) رعایت این موارد الزامی است:

- **اولین پارامتر**: همیشه `ctx context.Context` اولین ورودی تابع باشد.
- **عدم ذخیره در Struct**: کانتکست عمر کوتاه دارد، استراکت ممکن است عمر طولانی داشته باشد. این کار باعث نشت حافظه می‌شود.
- **زنجیره را نشکن**: داخل توابع از `context.Background()` استفاده نکن؛ کانتکست ورودی را بسط بده.
- **تضمین آزادسازی**: همیشه از `defer cancel()` استفاده کن تا منابع تایمر و رفرنس‌ها آزاد شوند (حتی اگر تایم‌اوت رخ دهد).
