# فلسفه و ماهیت Context

کانتکست در Go **فقط** یک سیستم سیگنال‌دهی برای توقف عملیات است.

## اهداف اصلی:
1. **Resource Management**: آزادسازی منابع (حافظه، گوروتین).
2. **Prevention of Leaks**: جلوگیری از ایجاد "گوروتین‌های یتیم".
3. **Flow Control**: مدیریت زمان اجرای درخواست‌ها.

> [!IMPORTANT]
> کانتکست برای انتقال دیتا یا مدیریت State ساخته نشده است؛ هدف آن فقط کنترل "زمان مرگ" عملیات است.
