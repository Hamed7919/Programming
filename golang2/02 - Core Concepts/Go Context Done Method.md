# متد Done در کانتکست Go

متد `Done()` قلب تپنده مدیریت همزمانی در Go است.

## ساختار فنی
- امضا: `Done() <-chan struct{}`
- خروجی: یک کانال (Channel) فقط خواندنی.
- نوع داده: `struct{}` (بدون مصرف حافظه، فقط برای سیگنال).

## مکانیسم عمل
1. تا زمانی که عملیات در جریان است، خواندن از این کانال **Block** (منتظر) می‌ماند.
2. به محض اینکه کانتکست `cancel` یا `timeout` شود، این کانال **بسته (Close)** می‌شود.
3. در Go، خواندن از یک کانالِ بسته شده بلافاصله **Unblock** می‌شود.

## چرا struct{}؟
چون به دیتا نیاز نداریم؛ فقط "وقوع یک اتفاق" (Event) برای ما مهم است. صفر بایت حافظه اشغال می‌کند.
