# محرک‌های لغو کانتکست

سه عامل اصلی باعث فعال شدن سیگنال `Done()` می‌شوند:

1. **بManual Cancel**: با صدا زدن تابع `cancel()`. کاربرد: توقف دستی ورکرها.
2. **بTimeout**: لغو خودکار پس از مدت زمان مشخص (مثلاً ۵ ثانیه). کاربرد: کوئری‌های دیتابیس.
3. **بDeadline**: لغو خودکار در یک زمان مطلق (مثلاً ساعت ۱۰:۳۰).

| نوع | عامل لغو | زمان لغو |
| :--- | :--- | :--- |
| WithCancel | برنامه‌نویس | هر زمان |
| WithTimeout | سیستم (Runtime) | پس از مدت معین |
| WithDeadline | سیستم (Runtime) | در زمان مشخص |
