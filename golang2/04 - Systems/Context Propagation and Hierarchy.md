# سلسله مراتب و انتشار کانتکست

کانتکست در Go به صورت یک **درخت (Tree)** عمل می‌کند.



> [!NOTE] Title
> کانتکست در Go یک ساختار درختی (Tree) می‌سازد که ریشه آن همیشه `Background` یا `TODO` است



## قانون انتشار (Propagation)
- لغو شدن از **بالا به پایین** است.
- اگر `Parent Context` لغو شود، تمام `Child Context`های آن نیز لغو می‌شوند.
- لغو کردن یک Child، تاثیری روی Parent ندارد.

## کاربرد در معماری
در یک Request HTTP، کانتکست اصلی درخواست به تمام لایه‌ها (DB, Cache, External API) پاس داده می‌شود. اگر کاربر مرورگر را ببندد، تمام عملیات‌های زیرمجموعه زنجیره‌وار متوقف می‌شوند تا منابع هدر نرود.

همیشه یک درخت است.
```
request ctx
   │
   ├── db ctx
   ├── cache ctx
   └── worker ctx
```
